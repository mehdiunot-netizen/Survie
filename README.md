Survie Maudite

Jeu de survie 2D pour iPhone, développé en HTML, CSS et JavaScript.

Le jeu

Survis dans un monde dangereux, affronte les ennemis, récupère des ressources et améliore ton équipement.

Chaque mort permet d’apprendre et de progresser.

Comment jouer

Le jeu se trouve dans le fichier index.html.

Il pourra être lancé directement dans le navigateur grâce à GitHub Pages.
